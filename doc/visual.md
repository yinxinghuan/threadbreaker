# Threadbreaker 视觉规范

## 1. 视觉命题

“看见压力的走向，再亲手把它切断。”玩家是 FIELD OPERATIONS DESK 中的远程基础设施污染控制员：操作台负责控制，结算的巡检回传负责证明操作对真实管道造成的结果。不用装饰粒子营造虚假的复杂度。

## 2. 构图与镜头

- 固定正交俯视；顶部 12% 为低噪任务轨，中部 72% 为链体与路线，底部 16% 为玩家安全带。
- 玩家始终在拇指可达的底部带；教程不覆盖链体、弹道或路线刻线。
- （已被当前 CRT 方案取代）旧热敏纸帧只保留为改造前证据；当前结算在同一显像管内切到设施摄像输入。

## 12. CRT 机房终端（当前方案）

- 使用 `ui-style-library` 的 BSOD Pixel / CRT 正式方向。CH-03 程序、污染链、HUD、暂停和结算媒体共享厚重显像管；不是外加扫描线滤镜。
- contained/residue/breach 三张固定机位工业巡检 JPEG 由权威 cleared/overrun、splits 与残余片段确定性选择；动态原因、侵入和建议仍来自冻结快照。
- CRT 采用低饱和绿磷光、硬边小字、内凹玻璃、CSS 像素定标扫描调制、边缘孔径与一次视频同步；无纸张、印章、打印或循环 glitch。
- reduced-motion 直接显示静态摄像图。资产来源和镜头连续性见 `doc/assets.md`。

## 3. 色彩

- 墨黑 `#171814`：背景；纸白 `#EAE6D8`：链体与主要文本；锈橙 `#E35B38`：下压/失败；青绿 `#6EC4A5`：玩家和安全带；灰褐 `#777568`：障碍与辅助刻线。
- 状态同时用形状、线型或文字表达，不只靠颜色。

## 4. 字体

- 系统无衬线：`Inter, ui-sans-serif, "PingFang SC", sans-serif`；标题 18/700，HUD 12/700，教程 16/700，结果 28/800。

## 5. 形状、材质与光

- 全部 2D 硬边、无阴影；链节为有朝向缺口的椭圆切片，障碍为三叉结点，玩家为开口楔形。
- 禁止渐变、软阴影、玻璃卡、霓虹光晕。

## 6. 素材系统

- 无外部图像、字体或音频素材；事件声由 Web Audio 程序化合成。Canvas 图形由权威状态或只读反馈观察器生成。
- 正式 GPU 灵体尚未集成；不得把当前路线刻线称为 `curl-noise-spirit-field` 效果。

## 7. UI 与图标

- 暂停/继续使用自绘线性 SVG，`2px` 直角端点；声音用两行机械标签 `SOUND ON/OFF / 声音开/关`，两者触控框均至少 44px。
- 结果操作为实心纸白矩形；不使用 emoji 或通用圆角卡片。
- 结果帧使用直角档案边框、等宽任务号与单一状态印记。`cleared` 是十二格管道采样与恢复流线；`overrun` 是纵剖网格、真实危险带、残余片段和突破坐标，两者不是同图换字。

## 8. 动效与特效

- 炮塔跟手同帧；命中用 200ms 硬边楔片；中段断裂用 320ms 双向碎片与片段裂纹；反向加速片段持续保留锈橙刻痕。
- 链节背后的实色短线直接读取同一 `routeCurl()`，显示当前权威流向；它不是半透明拖尾，也不冒充正式 GPU Skill。
- 链体进入危险区后，安全带在墨绿/褐红之间硬切并出现锈橙斜线；清波时四组青绿直线从两侧收束。无渐变、软光、烟花或屏幕震动。
- reduced-motion 停止碎片、压力脉冲和收束线位移，但保留裂纹、刻线、危险斜线和最终状态。
- 终局只有一次 `signal lock → develop → static evidence` 编排，总长 `460ms`；reduced-motion 直接显示静态证据。影像显影后不再循环动效，适合截图。

## 9. 参考转译

- Centipede：继承横移、遇边/障碍下压、射断成片段的长期验证骨架。
- curl 场：只转译成“可见且权威的路线偏置”，当前不复刻 The Spirit 的 GPU 粒子外观。

## 10. 反模式

- 禁止蛇形自由滑行、吃食物长大或自身碰撞，那会重复 Circuit Serpent。
- 禁止只画随机流线却不影响转向；禁止为了热闹添加半透明粒子、渐变、发光或屏幕震动。
- 禁止双语并排、键盘提示、虚拟摇杆和独立射击键。
- 禁止伪旋钮、无功能仪表灯、通用玻璃卡和与终局数据无关的“现场照片”。

## 11. 垂直切片验收

- 390×844 与 320×568 首屏 3 秒内看懂拖动和自动射击；HUD 不压场。
- 命中中段可见地拆成两片，后片反向且压力升高；路线刻线与实际转向一致。
- ready、playing、pause、cleared、overrun 在同一视觉系统中；所有交互目标 ≥44px。
## 2026-08-01 CRT 与结算层级修订

- 游玩和结算统一显示 4px 电子束扫描、克制 RGB 荧光栅格、曲面玻璃高光及强边缘暗角，使后置程序也明确运行在同一台 CRT 中。
- 结算只保留频道标题、全幅巡检影像、叠在影像底部的一条结果/遥测带，以及重试/声音操作。
