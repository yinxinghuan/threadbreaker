# Threadbreaker 需求文档

## 1. Overview

Threadbreaker 是一款 45 秒单指 Centipede 防线游戏：玩家在底部安全带拖动炮塔自动射击，把下压的分节链体打断，同时根据可读的旋流路线决定先切哪一段。

### 界面简报

- 玩家与场景：移动推荐流中的首次玩家；`390×844` 与 `320×568` 竖屏，3 秒内理解“拖动躲避、自动射击”。
- 核心决策：切头延缓下压，或切中段制造更多、但更短更快的碎片；玩家还需借助路线箭头预判链体下一次转向。
- 情绪承诺：克制、精确的压力管理；每次断裂既是解围，也是制造新威胁。
- 状态：ready、playing、paused、cleared、overrun；单局 45 秒，结果后一次触摸立即重开。
- 无身份、头像、排行榜、平台 UUID、海报和发布接入。
- 世界观岗位是“远程基础设施污染控制员”：游玩画面是操作台，结算接收由本局终局状态生成的管道 / 显微巡检回传，而不是固定结算插画。

## 2. Visual Design

- 灰盒采用“地形图切线”方向：深墨底、骨白链节、锈橙危险、青绿安全带；没有渐变、辉光、半透明粒子或装饰性噪声。
- 权威 curl 路线以低密度短线和转向箭头显示；链节、障碍、弹丸和命中区域均对应碰撞实体。
- HUD 固定在顶部安全区，教程只在 ready 状态占一行，不遮挡路径或链体。
- 本轮不宣称已接入正式 `curl-noise-spirit-field` GPU 技能；它只验证权威路线场。正式技能的 ping-pong、4D simplex derivative 与许可合同留待触屏确认后实施。
- 结算把同一 CRT 切换到封闭设施巡检摄像：overrun 选择 breach；cleared 且 `splits≥4` 或残余片段 >8 选择 residue；其余选择 contained。拆分、残余、最深侵入和危险带继续作为真实遥测叠层。

## 3. Game Mechanics

- 权威场地为归一化 `360×640`，固定步长 `1/120s`；渲染可为 30 或 60fps，物理结果一致。
- 单局 `45s`，玩家炮塔在 `y=590` 的安全带内，水平范围 `x=24..336`，垂直可拖 `y=552..612`；自动射击间隔 `240ms`，弹速 `520 units/s`。
- 初始在 `y=160/208` 生成 2 条链，每条 9 节；第 12 秒与第 26 秒各补 1 条 8 节链。链节半径 `8`，水平速度随时间从 `58` 增至 `92 units/s`。
- 链头碰边或进入障碍的下一步会下压 `24` 单位并转向。权威路线场按 `(seed,row,column,timeBucket)` 生成离散 curl 值；它改变每个链片在障碍处向左/向右的选择，并以同一函数绘制路线刻线。
- 命中任一链节扣除 1 点生命；链节生命为 1。命中中间节时链体立即拆成前后两个独立片段，后片反向，且两个片段获得 `1.08×` 速度；这是风险收益核心，不自动合并或返还。
- 场上有 12 个固定障碍节点。命中障碍 3 次可清除；链体撞到障碍会下压并依据 curl 值选择离开方向。
- 弹丸命中半径 `7`；玩家与链节中心距离 `<17` 或任一链节进入 `y≥548` 即失败。坚持 45 秒或清空所有链体则完成。
- 分数：链节 `100`；连续 `1.2s` 内命中倍率从 `×1` 增至 `×4`；清除障碍 `60`。分裂本身不加分。
- 短促不透明碎片用于命中/断裂确认，反馈层最多保留 `56` 个、`200–320ms` 后消失；权威模型自身的 burst 仍保持最多 `48` 个、`220ms`。两者均不参与判定。`prefers-reduced-motion` 时取消碎片位移，只保留硬边形状。
- 被分裂后加速的片段在链节上增加锈橙裂纹，权威 `routeCurl()` 在链节背后生成短促流向刻线；危险带进入时显示硬边斜线脉冲，均只读取权威状态。

## 4. Controls

- 仅 Pointer Events。`pointerdown` 捕获主触点并立即进入 playing；`pointermove` 将炮塔映射到安全带内的 x/y；`pointerup` 结束拖动但自动射击继续。
- `pointercancel`、`lostpointercapture`、页面隐藏和窗口失焦立即清除拖动态并暂停，不保留卡住的输入。
- 不提供键盘玩法、虚拟摇杆、方向键或额外射击按钮。顶部提供 `≥44×44px` 暂停与 `SOUND ON/OFF / 声音开关` 两个辅助控件。
- Canvas 使用 `touch-action:none`；入口含全局 iOS 长按防护。

## 5. Win / Lose Conditions

- `cleared`：45 秒结束仍存活，或场上链节清零且最后一次增援已出现。
- `overrun`：链节进入安全带或撞到玩家。
- 结算显示结果、分数、存活秒数、断裂次数及清晰原因；主动作“再守一次 / Try again”，按下后 `≤100ms` 回到新一局。
- 终局数据先冻结，再经过 `460ms` 信号锁定 / 显影进入静态现场回传；`prefers-reduced-motion` 直接显影。任务号只由本局 seed 派生，不包含平台 UUID 或个人信息。
- 灰盒 Keep 门槛：首轮 3 秒内发生可理解的拖动与自动射击；至少一次分裂改变目标优先级；失败可归因；结果后 3 秒内有自然重开欲。前三项可自动验证，最后一项等待用户触屏判断。

## 6. Sound Effects

- 无背景音乐和外部素材。首次真实 Pointer 手势后创建/恢复 Web Audio；手势前完全静默，不触发 autoplay。
- 自动射击：`760→610Hz` 方波 `26ms`，单音增益 `0.045`，限频 `120ms`；核心仍以 `240ms` 自动开火。
- 普通段命中：`204–276→150Hz` 三角波 `42ms`，音高随 `×1..×4` 连击轻微抬升，限频 `55ms`。
- 断裂：`258→208Hz` 方波与延后 `34ms` 的 `392→310Hz` 三角波；反向加速片段另有 `420→285Hz` 锯齿短音，三者材质可区分。
- 下压危险带：`96→82Hz` 方波 `85ms`、限频 `420ms`；玩家受击：`148→54Hz` 锯齿 `240ms` 加 `105ms` 硬质带通噪声；清除波次：`312/468/624Hz` 三段收束音。
- 所有声音经过主增益 `0.2` 与 DynamicsCompressor（threshold `-24dB`、ratio `10:1`）；同时 voice 上限 `8`，超限停止最旧声部。
- `pointercancel`、lost capture、暂停、页面隐藏、blur 与重开立即停止全部现有节点；恢复不叠音。静音写入 `threadbreaker_muted`，刷新后保持。
- 可用振动只增强断裂（`12ms`）与受击（`18/30/28ms`），关闭/不支持时不影响任何信息。
- 回传完成使用一声短促的机械锁定 / 止纸音；声音只确认结果数据已冻结，不承担唯一信息。
