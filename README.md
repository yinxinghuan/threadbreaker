# THREADBREAKER

30–45 秒单指 Centipede 骨架：拖动巡检器、自动射击，切断持续下压的分节链体；中段断裂会制造新的反向片段，必须在危险带突破前管理分裂风险。

正式版采用 1980–1990 年代大型 CRT 污染控制终端包装，三档本地预置巡检摄像结果由权威结局、断裂数与残余段数确定；支持 AlterU 身份、永久 UUID、Top 50 排行榜与平台外诚实降级。

线上入口：`https://yinxinghuan.github.io/threadbreaker/`

永久 UUID：`b9ea9b06-16fe-4b0c-aa9f-0927fd604080`

npm install
npm run dev -- --host 127.0.0.1 --port 5187

npm run build
